## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + Z` / `Cmd + Z` | Undo last action |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Redo action |
| `Delete` / `Backspace` | Delete selected layer (text, sticker, drawing) |
| `Ctrl + V` / `Cmd + V` | Paste image from clipboard |
